方案 A · 列表卡片纵向堆叠

每个选项一整行：左 emoji 大图标 + 标题，下面一行短描述；选中态用 emerald 边框 + 浅底色 + 右侧勾。

  • ✓最稳：每个选项完整呈现，零信息损失
  • ✓左对齐 + 等行高 → 阅读节奏整齐
  • ✓语气保留示例引用 + 标签
  • −占垂直空间最多，文章类型 4 行 + 语气 3 行

推荐场景：用户偏好详细文案、不介意滚动；左栏内容相对稳定

方案 B · 2×2 网格 + 列表

文章类型 4 项天然适合 2×2 网格；语气 3 项继续走列表（3 项也只占 3 行）。

  • ✓最平衡：节省一半垂直空间
  • ✓2 列网格 emoji 居左 + 标题加粗，扫读快
  • ✓语气仍保留描述 + 副标题
  • −语气示例引用被精简，主标题旁副标题

推荐场景：日常使用、希望左栏紧凑但仍可阅读

方案 C · 芯片 + 详情卡

所有选项压成圆角胶囊横排（自动 wrap 换行），下方独立卡片展示当前选中项的完整描述。

  • ✓最紧凑：4 项芯片可挤一行
  • ✓详情卡始终展示当前选项完整说明
  • ✓视觉最轻、最现代（类似 Apple Settings 风）
  • −未选中项只有 emoji+标题，看不到描述

推荐场景：用户已熟悉选项含义、追求极简紧凑
