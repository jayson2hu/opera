# M0 · 设计 Token & 全局样式

## S0.1 · 引入 Noto 字体
**做**：`index.html` `<head>` 加 Google Fonts 链接，预连接 `fonts.googleapis.com / fonts.gstatic.com`，加载 `Noto Serif SC` (700/800/900) + `Noto Sans SC` (400/500/700)。
**自测**：DevTools Network 中能看到 woff2 加载；`document.fonts.ready` resolved 后两个字体在 `document.fonts` 内。
**验收**：首屏渲染未出现 FOIT >300ms；离线时降级到 `PingFang SC`。

## S0.2 · 全局字体声明
**做**：`index.css` 把 `body { font-family: 'Noto Sans SC', 'PingFang SC', system-ui, sans-serif; }`；新增 `.font-serif { font-family: 'Noto Serif SC', 'Songti SC', Georgia, serif; }`。
**自测**：在测试页里写 `<h1 class="font-serif">中文标题</h1>`，DevTools Computed → font-family 显示 Noto Serif SC。
**验收**：现有页面正文字体平稳过渡到 Noto Sans，无视觉跳变；标题 `font-serif` 类生效。

## S0.3 · Tailwind 色板扩展
**做**：`tailwind.config.ts` 的 `theme.extend.colors` 加四组：
- `primary-{50..900}` 暖橘（`#FEF7EE … #773414`）
- `accent-{50..600}` 紫（`#F5F3FF … #7C3AED`）
- `emerald` 用 Tailwind 默认即可
- `neutral-{50..900}` 暖灰（`#FAF6F1 … #1C1815`）

**自测**：在任意组件上加 `className="bg-primary-500 text-accent-600"`，背景与文字颜色与设计稿一致。
**验收**：所有现有页面无回归；`grep -rn '#[0-9A-F]\{6\}' src/` 不再出现重复散落的颜色（允许保留组件库内部）。

## S0.4 · 阴影与圆角扩展
**做**：`theme.extend.boxShadow` 加 `card: '0 1px 2px rgb(120 90 50 / .04), 0 1px 3px -1px rgb(120 90 50 / .05)'` 与 `card-hover: '0 6px 16px -6px rgb(120 90 50 / .12), 0 2px 6px -2px rgb(120 90 50 / .06)'`；`borderRadius.card: 18px` / `.paper: 22px`。
**自测**：`shadow-card hover:shadow-card-hover` 能在卡片上看到浮起效果。
**验收**：与设计稿首页 3 大卡片阴影一致。

# M2 · 三件套交互组件

## S2.1 · `Toast` 单例 store
**做**：`src/lib/toast.ts` 用 `useSyncExternalStore` 暴露 `toast(msg)`；订阅者注册一个 listener，set 后 1.6s 清空。
**自测**：连续调 3 次 `toast('a') toast('b') toast('c')`，只显示 c。
**验收**：无依赖 React Context；任意组件可直接调用。

## S2.2 · `Toast` 视觉组件
**做**：`<OperaToast/>` 渲染到 body：`position: fixed; top: 18px; left: 50%; transform: translateX(-50%)` 深色胶囊 + 绿色对勾。无入场动画。
**自测**：在 App 根挂载一次；点击三处复制按钮看到顶部提示。
**验收**：与设计稿"顶部居中、深底白字"一致；不会推动布局。

## S2.3 · `TopicField` 紧凑态
**做**：`src/components/TopicField.tsx`，左栏内紧凑 textarea/input；右上角 ⤢ 按钮（28×28 圆角白底）；底部字数与字数达标颜色（绿/黄）。props `{ value, onChange, disabled, minLen, multiline, placeholder, tone }`。
**自测**：键入时 onChange 触发；字数未达 minLen 时边框黄色。
**验收**：与设计稿紧凑态完全一致；⤢ 按钮 hover 出现 tone 主色。

## S2.4 · `TopicField` 弹出模态
**做**：点 ⤢ 打开居中 modal：标题"编辑选题" + 笔图标 + 关闭 X；中部大 textarea（rows=8, 16px 字号, 8 行距）；底部字数 + "清空 / 完成" 按钮。点击遮罩或 Esc 关闭。
**自测**：模态打开 200ms 内自动 focus 末尾；Esc 关闭；点 X 关闭；点遮罩关闭。
**验收**：与设计稿 modal 一致（圆角 28、阴影、按钮配色）。

## S2.5 · `EditableBlock` 段落容器
**做**：`src/components/EditableBlock.tsx`，包裹任意文本元素，悬停时右上角 -3px/+1px 浮现工具条（改写 + 2 个 alternates）。props `{ as, text, alternates, tone, onCustomEdit, className }`。
**自测**：鼠标进入显示工具条；离开消失；点 alternate 直接替换 contentEditable 文本。
**验收**：与设计稿浮条样式一致；不影响段落自身的 ContentEditable。

## S2.6 · `EditableBlock` 自定义改写面板
**做**：点"改写"在段落正下方弹出小面板：标题"只改这一段·不影响全文" + 紫色图标方块 + 3 个 alternate 芯片 + 自定义输入框 + 应用按钮。点击外部关闭。
**自测**：自定义输入提交 → 调用 `onCustomEdit(prompt)`；返回字符串后替换段落文本并高亮闪 1.4s。
**验收**：面板宽度跟段落同宽，z-index 30；自定义和 alternate 互不干扰。

## S2.7 · `EditableBlock` Loading 覆盖层
**做**：触发改写后显示半透明白底 + 3 个跳动圆点 + "笔灵正在修改这一段…"。
**自测**：模拟 `onCustomEdit` 延迟 700ms 后返回，loading 出现并消失；高亮闪烁完成。
**验收**：与设计稿一致；不会影响其他段落。

## S2.8 · `useTyping` 打字 hook
**做**：`src/hooks/useTyping.ts`，输入 `{ text, on, duration }`，返回 `{ text, done }`。on=true 时按线性比例返回前 N 字。
**自测**：on=false 立即 done；on=true 在 duration 内逐字推进。
**验收**：暂停/恢复光滑，无字符跳跃。
