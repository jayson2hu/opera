## 规划与架构核对

| 最新规划 | 代码职责 | 核对结果 |
|---|---|---|
| W0 保留三流程与默认入口 | App / 三个 Page / 偏好 | 保留公众号、改写、原创；没有将离线原型的模型模拟器放入产品 |
| W1 稿件与版本安全 | useDraftWorkspace / draftWorkspace / localStorage | 独立 ID、schema/revision、同步恢复、迁移、历史、失败反馈；版本确认前保护原稿 |
| W2 可编辑和候选确认 | BodyEditor / EditableBlock / GenerationReview | 人工编辑可离线；整稿及段落均确认后应用，完整指纹防过期覆盖 |
| W3 当前内容局部生成 | currentContent / FastAPI _current_content / provider adapters | 目标块使用当前正文；旧协议保留；真实 HTTP 验证六个目标与两种模型协议 |
| W4 真实篇幅与解释性检查 | qualityChecks / resultParameterKey | 三流程各自目标保留；配置变化不改旧稿的来源；无传播效果百分比 |
| W5 验证与部署 | CI / Docker / tests/acceptance | 新增真实镜像构建与 HTTP 代理门禁、Ruff 和运行器防误连回归；待合入后由远程 CI 执行 |

生产路径仍是 React → 同源 Nginx `/api` → FastAPI → provider adapter。
旧 Node 后端继续禁用。更新了 PROJECT 的遗漏接口/事件及 CLAUDE.md 中陈旧的
单流程范围和失效文档路径，避免旧计划覆盖最新获批范围。

本轮没有引入登录、云稿件、自动发布、计费、多人协作或新的应用框架。
图片仍临时保存；同稿多窗口无原子协作保证；JSON 备份没有通用导入界面。
这些是已声明边界，不应据此宣称已具备云端发布工作台能力。

## 剩余门禁与维护项

- 真实模型：需要项目专用配置和允许的调用额度；本轮实际付费调用为 0。
- 原生设备：Safari/iOS、真实中文输入法，以及人工内容/图文质量验收仍待执行。
- 远程 CI：配置已补齐；本轮未提交、推送或触发远程 CI，不能用本地通过代替它。
- 依赖维护：当前 npm audit 有 8 项开发/构建链告警（3 high、4 moderate、1 low），
  涉及 Vitest/mocker、Babel、humanfs、baseline-browser-mapping、brace-expansion、
  browserslist、nanoid；本轮没有批量升级锁文件。它们未被打包成 Nginx 运行时依赖，
  但应在后续依赖维护中处理。
- 后端有 2 条依赖弃用提醒，依赖整体解析仍未锁定。Ruff 已显式固定版本和规则，
  不再把不同默认规则下的结果混写为同一门禁。
- 公网运行仍需要鉴权、用户归属、限流/费用控制、监控和回滚方案。
